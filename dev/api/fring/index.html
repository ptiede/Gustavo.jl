Fring

The solver stages and their pluggable smoothers: the fringe search, stationization, the bandpass solve, and adhoc phasing.

Gustavo.Fring — Module
Fring

VLBI fringe fitting on top of the unified Gustavo.Calibration model framework and the Gustavo visibility model (EHT-HOPS-inspired, Blackburn et al. 2019, but with globally-closing per-feed solutions): per-baseline FFT delay/rate search, stationization, bandpass and adhoc-phase stages, and the diagnostics over them.

Gustavo.Fring.AbstractAdhocSmoother — Type
AbstractAdhocSmoother

How the AdhocPhase solver fits the per-AP station phase tracks the adhoc solve produces (solve_adhoc_phasing) under the adhoc component's prior: PerTrackAdhocSmoother (the default) or JointKalmanSmoother.

Implementing a smoother

Define a struct and:

Gustavo.Fring.apply_adhoc!(sm::MySmoother, phase, track_w; obs, priors, resolved)

the single dispatch point; mutates phase in place. phase and track_w are DimArrays over (AntennaName, FeedNode, Ti): each (station, feed node) phase track and its per-AP coherent weight, Ti carrying the AP epochs in seconds. Each AP of phase is centered on the cells covered throughout the scan; the solver's gauge is applied after smoothing. obs holds the SNR-gated, source-corrected observations: obs.val, obs.w and the gate obs.mask over (AntennaPair, FeedPair, Ti), and obs.nodes, each cell's ((a, na), (b, nb)) — the station index and feed node at either end. priors[a] is station a's prior along time: nothing, a RandomWalkPrior or an OUPrior. resolved, over (AntennaName, FeedNode), receives the prior each track was fit under, its hyperparameters fixed. The default apply_adhoc! fits each (station, node) track that carries data independently through the per-track hook, so a smoother that acts track by track implements only

Gustavo.Fring.smooth_track!(sm::MySmoother, track, w, prior) -> resolved prior

which overwrites track with its fitted values; lookup(track, Ti) gives its times.

A smoother declares which adhoc components it can solve with

Gustavo.Fring.can_fit(sm::MySmoother, tc::Calibration.GainComponent, geom) -> Bool

checked at model-compile time. The default is the capability of the solve machinery — per-AP constant phase over the global band, SharedFeeds or PerFeed, with no prior or a RandomWalkPrior or OUPrior along Ti; JointKalmanSmoother restricts to SharedFeeds (its Kalman state holds one phase per station) and to a proper prior: an OUPrior, or a RandomWalkPrior with an init.

Every smoother carries its solve options in an options::AdhocOptions field; see AdhocOptions.

Gustavo.Fring.AbstractSearchAlgorithm — Type
AbstractSearchAlgorithm

How the delay search lays out its FFT grid. Built-ins: FullGrid and HierarchicalMBD.

A custom algorithm subtypes this and defines

Gustavo.Fring._mbd_axes(alg, freqs, fax, tax, rates, opts, ::Type{C}) -> mbd_axes or nothing

returning nothing to run the single full-grid FFT, or the hierarchical band geometry to run the two-stage search. C is the search's compute type (the visibility block's eltype), needed to build any FFT plans the geometry carries. There is no fallback: an algorithm with no method is an error rather than a silent switch to a different search.

Gustavo.Fring.AdhocOptions — Type
AdhocOptions(; snr_floor = 1.0, phase_rewrap_iters = 3, source_iters = 10,
             source_tol = 1.0e-6, complex_iters = 2, eltype = nothing)

The solve options every AbstractAdhocSmoother carries in its options field, e.g. PerTrackAdhocSmoother(; options = AdhocOptions(; snr_floor = 0.0)).

snr_floor gates the seed pass only (the phase-extraction solve that fixes the global 2π branch); complex_iters Gauss–Newton passes then re-fit the tracks against the complex residuals with every AP entering ungated (complex_iters = 0 keeps the seed). phase_rewrap_iters bounds the rewrap passes of each solve. source_iters alternations between the station tracks and the per-(baseline, product) source phases run until no source phase moves by more than source_tol radians, not counting a move that per-station constants absorb; source_iters = 1 fits no source term.

The solve works in the real type of the summed visibilities (Float32 for an MSv4 store); eltype, a real floating-point type, names another.

Gustavo.Fring.Cauchy — Type
Cauchy()

ρ(u) = ln(1 + u). Redescending — weight falls off as 1/u, so a far outlier is suppressed much harder than under SoftL1 or Huber, at the cost of a loss that is no longer convex in the residual.

Gustavo.Fring.FringeSearch — Type
FringeSearch(; delay_window, rate_window, oversample, quad_interp, algorithm, steer_cells)

Options for a fringe search: fit(FringeSearch(...), ps) searches every scan of ps, and baseline_fringe_search one baseline.

Every cell holding usable data yields a peak with its signal-to-noise and false-alarm probability; no detection threshold is applied here — admission to the station solve is Stationization's decision, taken on the recorded pfa.

  • delay_window : (lo, hi) delay search window in seconds. Default ±1 µs.
  • rate_window : (lo, hi) fringe-rate search window in Hz. Default ±0.8 Hz. Narrowing it buys no speed (the FFT spans the whole plane), only a smaller false-alarm trial count, while a window narrower than the true rate spread hides a station outright. Keep any choice well inside the ±1/(2Δt) Nyquist rate, past which a peak is an alias of its own wrap.
  • oversample : zero-padding factor per axis, equivalently the number of grid cells laid across the main lobe of the delay response. It sets which lobe the search finds, not how accurately the delay is then measured — quad_interp polishes the peak off-grid — so it only has to be fine enough to tell the main lobe from the alias lobes a gapped frequency axis puts beside it. :auto (default) therefore reads it off that axis: 2 for contiguous channels, rising to 8 as the bands sparsify toward the HierarchicalMBD crossover. An explicit positive Int overrides it; raise it if detections are landing on a multi-band alias, or lower it if the axis is contiguous and the search is the bottleneck. Cost is quadratic — the grid is oversample·nchan × oversample·ntime, so 8 is ~16× the work of 2. _resolve_oversample gives the rule and the measurements behind its thresholds.
  • quad_interp : polish the peak on the exact matched filter (sub-cell, per-axis parabolic steps on the true objective — _polish_peak_exact!). Default true.
  • algorithm : an AbstractSearchAlgorithm — FullGrid or HierarchicalMBD — or the sentinel :auto (default), which picks between them from the frequency axis: HierarchicalMBD when the axis has ≥ 2 band blocks and the common grid would be > 4× the real channel count (mostly zero-padding), else FullGrid. Contiguous-band data (e.g. VLBA) always takes the full-grid path.
  • steer_cells : the trial count of a steered measurement's pfa, the cells covering the uncertainty of the predicted fringe location (see fit(::FringeSearch, ps; at)). Default 9.

Gustavo.Fring.FringeSearchMap — Type
FringeSearchMap

The windowed delay–rate matched-filter surface of one visibility block, produced by baseline_fringe_map and fringe_search_map — the classic false-fringe diagnostic. The coordinates, map and detection are at the search's compute precision, the real type of the visibilities. Fields:

  • snr — DimArray of |D| / noise over (FringeDelay, FringeRate) (s, Hz; the in-window grid, ascending), in the same units as the detection's snr, so the map's peak sits at ≈ detection.snr. Its refdims name the scan, baseline and feed pair when the map came from fringe_search_map.
  • detection — the refined peak, exactly as baseline_fringe_search returns it.
  • ncells — effective number of independent search cells (see fringe_pfa).
  • pfa — fringe_pfa(detection.snr, ncells).

Gustavo.Fring.FullGrid — Type
FullGrid()

One brute-force FFT over the common-Δf grid spanning the whole frequency axis. Simple and fast for contiguous bands (e.g. VLBA); on widely-separated narrow bands the grid is almost entirely zero-padding.

source
Gustavo.Fring.HierarchicalMBD — Type
HierarchicalMBD()

Hierarchical single-band → multi-band delay search (HOPS/fourfit style): a per-band in-band delay, then a multi-band delay over the band origins, which resolves the MBD ambiguity explicitly against the in-band delay. Far cheaper than FullGrid when narrow bands are spread over a wide span (VGOS-style). Throws when the frequency axis cannot support it: a degenerate or unsorted axis, fewer than two band blocks, band origins on no common grid or sharing a grid bin, a band-origin grid over 65536 points, or no delay or rate inside the search windows. algorithm = :auto runs the full grid in those cases instead.

Gustavo.Fring.Huber — Type
Huber()

ρ(u) = u for u ≤ 1, 2√u − 1 beyond: full weight inside the scale, L1 outside. Sharper than SoftL1 at the transition.

Gustavo.Fring.JointKalmanSmoother — Type
JointKalmanSmoother(; coherence_time = 10.0, options = AdhocOptions())

Fit every station's phase track of a scan at once: one multivariate Kalman filter and RTS smoother over the station phases, observing the baseline phase differences directly under each station's prior along Ti: an OUPrior, or a RandomWalkPrior with an init, which holds the common phase of all stations that the differences leave free. Closure and denoising happen in one estimator, which conditions better at low SNR than fitting each track after the per-AP solve. Seeded and rewrapped from the per-AP solve; see _solve_gp_joint!.

A station's hyperparameters given as hyperpriors are resolved per scan by type-II MAP on its per-AP track, with the track's level integrated out under a flat prior. A station without a track of its own takes the median of the resolved values of the stations whose prior has the same form (an OUPrior, or a walk of the same order); a station whose hyperparameters are fixed keeps them.

Requires one phase node per station (a SharedFeeds adhoc component), since its state carries one dimension per station.

coherence_time is the assumed atmospheric coherence time in seconds. It bounds how long a solved AP seeds the 2π branch of later ones; it does not enter any prior.

options is an AdhocOptions.

Gustavo.Fring.JointSmoother — Type
JointSmoother(; max_iterations = 200, max_em_iterations = 100, tolerance = 0.01,
              flat_span = 0.01, warn_fraction = 0.25, eltype = nothing,
              linsolve = KrylovJL_CG(; linesearch = true))

Fit the station bandpass against the actual complex visibilities, with each component's prior acting inside the solve rather than as a fit applied to it afterwards: the gains maximize their posterior with the per-scan source term profiled out, and the hyperparameters given as densities are fit by MAP-EM (solve_joint_bandpass!).

Because the per-scan source term absorbs a baseline's own structure, this suits a resolved or polarized calibrator. It solves one complex gain per (station, feed, frequency segment), so a model with both a phase and a log-amplitude shape must give them one frequency and one time segmentation per station; their priors and levels may differ. A model with only one of them holds the other at zero: unit amplitude, or zero phase.

It accepts components of the form GainComponent(ConstantTerm(); Ti = <GlobalTime, InstrumentScans or TimeBlocks>, Frequency = <any segmentation>, Feed = PerFeed(), prior = <nothing, or a RandomWalkPrior, OUPrior or CARMAPrior along Frequency>): a time segmentation whose segments each span several scans, solved one segment at a time. Beside a shape under a proper prior, the phase may also take a GainComponent(Delay(); …) on the same time segmentation: a delay over each of its frequency segments, which must hold whole spectral windows. Stations may have different models.

A level or delay beside the shape is flat, or under an IIDPrior(σ), in its own units (radians, log-amplitude, seconds), that draws it toward zero; set a station's own σ with with_antenna. The track's band constant, which the source term absorbs, stays free either way. Under PinAntenna the reference's track is zero, so a delay prior draws each station's delay toward the reference's.

Beside its shape, a station may also carry components with Ti = PerScan() and no prior, of any term, segmentation along frequency and feed tying: values that change from scan to scan, such as a phase level and a delay per group of channels,

groups = FreqGroups([1:1, 2:13, 14:25, 26:32])
level = GainComponent(ConstantTerm(); Ti = PerScan(), Frequency = groups, Feed = SharedFeeds())
delay = GainComponent(Delay(); Ti = PerScan(), Frequency = groups, Feed = SharedFeeds())
model = with_antenna(model, "NN"; phase = (; bandpass = shape, level, delay))

The shape and these terms are solved by alternation: the shape on the data with the per-scan terms divided out, then the terms scan by scan given the shape, fit to each scan's averaged visibilities beside free source terms, until no term moves by tolerance of its standard error. A shift common to every channel of a station and scan is absorbed by the source terms, so one parameter carrying it is held at zero; each parameter's information-weighted mean over the scans of a shape segment is held at zero, so the shape is the time-averaged bandpass. The terms start from zero, so the data must already be fringe-corrected, and every scan must hold a station without per-scan terms.

Each MAP solve stops once the undamped step would move no gain by more than tolerance of its standard error, and warns if max_iterations steps pass first. The hyperparameter fit stops once a cycle of it moves no gain by more than tolerance of its standard error, from one converged MAP to the next, with a warning if max_em_iterations EM maps pass first; the hyperparameters the gains no longer depend on are not converged. An unconverged solve still depends on its starting point.

Each step of the MAP solve is a linear system over every gain, solved matrix-free by linsolve, a Krylov method of LinearSolve.jl (e.g. KrylovJL_CG, KrylovJL_MINRES), preconditioned by a sparse Cholesky factorization. Its system is the Hessian of the posterior, which is not positive definite far from the mode, so a conjugate-gradient method should stop at nonpositive curvature (linesearch = true).

A phase prior depends on each segment's 2π branch, which the data leave open, so the solve chooses the branches of each phase piece once, by a Gaussian-sum Kalman filter over branch histories, before the MAP solve (see the fitting-under-priors page). A fitted piece whose range is below flat_span (radians or nepers) is reported flat rather than as a measured shape, and the solve warns when more than warn_fraction of its pieces are flat or without data.

The visibilities are reduced onto the frequency segments, and the gains and source terms held, in the real type of the summed visibilities (Float32 for an MSv4 store); eltype, a real floating-point type, names another. The steps are solved in Float64, the type the sparse Cholesky factorization supports.

Gustavo.Fring.OutlierMixture — Type
OutlierMixture()

Each detection is either explained by the station values, with its noise model's variance plus a floor s_c², or not, at probability π_c, with a value spread evenly over the delay or rate window its search covered. The class c is whether the detection relates the same feed index on its two stations or different ones. s_c and π_c are estimated by EM along with the station values, which a detection then weights by its probability of being explained, starting from the SoftL1 solution; no detection leaves the system. A detection more likely unexplained than not is reported.

Gustavo.Fring.PerTrackAdhocSmoother — Type
PerTrackAdhocSmoother(; coherence_time = 10.0, options = AdhocOptions())

Fit each (station, feed node) phase track of a scan on its own, under the adhoc component's prior along Ti (the default): its maximum a posteriori values.

  • no prior: the per-AP solve stands as is.
  • RandomWalkPrior: a σ given as a hyperprior is resolved per (station, feed node, scan) by type-II MAP on the restricted likelihood; the track is then the random-walk MAP.
  • OUPrior: hyperparameters given as hyperpriors are resolved per (station, feed node, scan) by type-II MAP, with the track's level integrated out under a flat prior; the track is then the level plus the zero-mean OU MAP.

Hyperparameters and levels are independent between scans.

coherence_time is the assumed atmospheric coherence time in seconds, the time for the phase to drift by one radian. It bounds how long a solved AP seeds the 2π branch of later ones; it does not enter any prior.

options is an AdhocOptions.

Gustavo.Fring.SoftL1 — Type
SoftL1()

Smooth L1: ρ(u) = 2(√(1+u) − 1). Quadratic for u ≪ 1 and linear far out, so a grossly inconsistent row contributes a bounded gradient instead of dominating the fit. The default, and EHT-HOPS's choice.

Gustavo.Fring.Stationization — Type
Stationization(; eltype = Float64, pfa_max, weak_sys_scale, loss, loss_scale,
                 irls_iters, systematic_delay, systematic_delay_rate,
                 max_em_iterations, em_tolerance)
Stationization{T}(; kw...)

Options for solve_antenna_systems!.

eltype (or T) is the floating-point type the station systems are built and solved in, whatever the detections' own type. The default Float64 is deliberate: weak rows sit ~1e-5 below accepted ones in √w, near Float32's rank tolerance.

pfa_max is the solve's one detection threshold, read against each detection's family-wise false-alarm probability (see Detection). It governs connectivity alone: a detection at or below it joins its two stations into one fringe group, and a (station, scan) is calibrated only when such a detection reaches it. A detection above it still contributes its row — with every systematic floor multiplied by weak_sys_scale — but never joins stations into a group, so a marginal baseline is measured at the fringe location the accepted detections fixed without being able to invent one.

Every correlation product contributes a row to the delay and rate systems; which parameters a row touches is set by the model's feed tying.

loss/loss_scale/irls_iters control robust downweighting: after each solve, each row's weight is rescaled by robust_weight(loss, (z/loss_scale)^2) at its noise-normalized residual z = resid·√w, and the system re-solved, up to irls_iters times. A false fringe is closure-inconsistent, lands far out in z, and is suppressed. Weights come from the noise model rather than the residual spread, so loss_scale cuts at the same effective threshold whatever the system size. loss = LeastSquares() disables downweighting.

systematic_delay (seconds) and systematic_delay_rate (seconds per second) are floors added in quadrature to a row's CRB uncertainty: w = 1/(σ_CRB² + systematic²). A rate row's floor is systematic_delay_rate times its scan's mean frequency (freq_mean), since a non-dispersive delay rate τ̇ moves the fringe rate by ν·τ̇. The default delay-rate floor, 2.3e-15, is the tropospheric floor measured at 43 GHz on the VLBA (a fringe-rate floor of 1e-4 Hz). Without a floor, data with no real systematics drives z to the numerical noise floor and the loss reweights rounding noise. weak_sys_scale multiplies the total σ of an above-threshold row, floor included.

A model whose priors along time give hyperparameters as densities, or the OutlierMixture loss, makes the solve an EM over those parameters, which stops once a cycle moves no log hyperparameter or outlier fraction, nor any floor's square relative to its detections' median noise variance, by more than em_tolerance, and warns after max_em_iterations.

Gustavo.Fring.TrackStatus — Type
TrackStatus

The outcome of fitting one piece (one spectral window) of a bandpass track, as the bandpass report records it: TrackNoData (no usable channel; unit gain), TrackSolved (fit, with frequency structure) or TrackFlat (fit, but its range is below JointSmoother's flat_span). θ alone cannot tell these apart: an unfitted piece reads back as unit gain and a flat one as a constant.

Gustavo.Fring.antenna_closure_residuals — Method
antenna_closure_residuals(dets; observable = :phase, feeds = (1, 1), pfa_max) -> Vector

For every closed triangle of antenna pairs in the detection stack dets (the AntennaPair × FeedPair shape a fringe search returns), the residual closure quantity of the chosen observable (:delay/:rate/:phase) on the feed pair feeds, using the measured detections: the signed sum around the triangle that station-based quantities cancel. On noiseless station-differenced data a pair (f, f) closes to ≈ 0; a pair of different feeds does not, since its legs read different feeds at the shared station. This is a property of the data alone, so no solution is needed to evaluate it.

A triangle counts only when all three legs are accepted detections (pfa <= pfa_max); a leg above that threshold carries an arbitrary value, which would enter the sum as noise rather than as evidence of non-closure.

Gustavo.Fring.baseline_fringe_map — Method
baseline_fringe_map(plane, f0, t0; opts = FringeSearch(), workspace = nothing)
    -> FringeSearchMap

Compute the full delay–rate SNR surface for one visibility block — the brute-force common-Δf grid/FFT (FullGrid), returning the windowed |D| plane (in SNR units) instead of only the peak. The PLANE is always the full grid — showing the complete sidelobe/alias structure is the point of the diagnostic — while the embedded detection honors opts.algorithm, so it is identical to what baseline_fringe_search (and the solver) returns. A diagnostic (a full-grid FFT per call — on VGOS-style axes this single plane is much more expensive than the hierarchical search that produced the solution), not a hot path. ncells and pfa are those of this one search.

Gustavo.Fring.baseline_fringe_search — Method
baseline_fringe_search(plane, f0, t0; opts = FringeSearch()) -> Detection

Search one (baseline, correlation product) block for the group delay, fringe rate, and phase that align the visibility phasor. plane is a DimStack on (Frequency, Ti) carrying :vis, :weights (inverse-variance) and :flags, such as one built from plain arrays by fringe_plane. f0, t0 are the delay/rate reference frequency and epoch, and the returned phase is referenced to them.

A sample is used when its flag is unset and it carries usable statistics — a finite visibility and a finite, positive weight. The two are independent: a flag that a caller clears makes the sample available again at the weight it already had.

The search runs natively at the visibility layer's own compute type C = eltype(plane[:vis]) (ComplexF32 or ComplexF64; FFTW supports no other complex type), so a ComplexF32 block returns a Detection{Float32}.

Gustavo.Fring.baseline_spectra — Method
baseline_spectra(data) -> DimStack

The visibilities of data, a processing set or a Measurement Set, laid out by station pair and feed pair, with the channels of all its spectral windows on one Frequency axis. Layers visibility, weight and flag, as the Measurement Sets hold them, over (Ti, AntennaPair, FeedPair, Frequency), cross baselines only, and scan_name over Ti. A cell no Measurement Set holds is NaN, of weight zero and flagged. Throws when two Measurement Sets hold the same cell.

Time averages give fewer, deeper spectra: average(ps, ByScan()) gives one per scan. Spectra of a scan before and after a solution show what it removed; a good fringe fit flattens the phase slope. DimensionalData's Makie recipes plot them directly, one line per baseline:

before = baseline_spectra(average(g, ByScan()))
after = baseline_spectra(average(calibrate(fr, g; flag_bad = false, apply_flags = false), ByScan()))
series(angle.(after.visibility[Ti = 1, FeedPair = At((1, 1))]))

Gustavo.Fring.can_fit — Method
can_fit(solver, tc::Calibration.GainComponent, geom::Calibration.DataGeometry) -> Bool

Whether solver (a fit specification, or the smoother one delegates to) fits the θ block of the compiled component tc on the geometry geom. The specification calls this once per component of its own model, when the model compiles, and throws an ArgumentError naming the solver and the component on the first false: a term nothing writes is a silent no-fit, not a smaller solve. State which models the solver fits in its own docstring.

geom makes a capability that depends on the data's sampling answerable: whether a time segmentation splits a scan is a property of the segmentation and the scan lengths together. Answer from the term wherever that suffices.

The default is false, so a solver that declares nothing fails on its first model term rather than returning a solution with zeros in it.

cat_scans(xs) -> DimStack or DimArray

Concatenate per-scan diagnostics — each a DimStack or DimArray with a Scan dimension, such as fringe_snr_table of each solution mapsets returns — along Scan. Gustavo.Fring.chi2 — Method
chi2(data, model; dims) -> DimStack

The χ² of data against model, Σ w |v - model|², summed over dims. data is a processing set, a Measurement Set or a baseline_spectra result, with the weight the inverse variance of each real component of the visibilities. model is a DimArray of model visibilities over some of the dimensions of baseline_spectra, used for every sample along the dimensions it lacks.

Returns layers chi2 and dof over the dimensions not in dims. Each usable sample (unflagged, positive weight, finite data) counts 2 degrees of freedom. The model's own free parameters are not charged; subtract them from dof.

Gustavo.Fring.coherence_report — Method
coherence_report(group; timescales = nothing, bandwidths = nothing,
                 debias = false, marginalize = true) -> DimStack

The coherence factor η = |Σ w·V| / Σ(w·|V|) of group, one scan (groupby(ps, ByScan())), against time-averaging interval and frequency-averaging width. Call it on the data before and after a solution to see how much coherence each averaging costs: a good solution keeps η ≈ 1 out to the whole scan and the whole spectral window. Layers:

  • time — over (Scan, AntennaPair, FeedPair, AveragingTime) (s).
  • freq — over (Scan, AntennaPair, FeedPair, AveragingBandwidth) (Hz); frequency bins stay within one spectral window.
  • time_pooled, freq_pooled — the same over (Scan, FeedPair, …), pooled over antenna pairs.

Each interval bins the data along its axis, sums coherently within every bin and pools the bins, so η ≡ 1 at native resolution and no gain model is needed. A cell with no usable data is NaN. timescales (s) and bandwidths (Hz) replace the default sweeps, which double from the native spacing until one interval spans the whole extent.

debias removes the thermal-noise bias, which otherwise pulls η below 1 at coarse averaging; it takes the weights as inverse variances per real component (w = 1/Var(Re V)). The debiased η pools unbiased per-bin powers and takes one square root at the end; where the pooled power does not clear 3σ of its null fluctuation it is NaN. marginalize measures each curve on data coherently averaged over the other axis first (the time curve on per-integration window averages, the frequency curve on per-channel scan averages), which raises the per-sample SNR the debias needs.

Per-scan results combine with cat_scans; pass the same timescales and bandwidths to every scan so the intervals line up.

Gustavo.Fring.default_adhoc_model — Method
default_adhoc_model(; feed = SharedFeeds(), prior = default_adhoc_prior()) -> GainModel

The default AdhocPhase model: one per-AP constant phase over the global band — a phase.adhoc component with Ti = PerIntegration(). feed is its feed tying: SharedFeeds() (the default) solves one track per station — residual atmospheric phase is non-birefringent, and a feed-common track contributes zero inter-feed phase in any feed basis, where a PerFeed() solve lets per-AP noise differ between feeds and so scatters the inter-feed phase. PerFeed() fits each feed's own track when the per-feed structure is real.

prior is the component's prior along Ti: by default an OUPrior with weakly informative hyperpriors (default_adhoc_prior); nothing leaves the per-AP solve unsmoothed.

The adhoc stage solves exactly one phase component and no logamp.

source
Gustavo.Fring.default_adhoc_prior — Method
default_adhoc_prior() -> OUPrior

The default prior of the adhoc phase along time: an OUPrior whose scale has a LogNormal hyperprior with median 10 s and whose σ has one with median 0.3 rad, each with log-standard deviation 1.

Gustavo.Fring.default_bandpass_model — Method
default_bandpass_model(; freq = ChannelBlocks(1)) -> GainModel

The default Bandpass model: a time-stable, per-feed ConstantTerm per frequency segment for each observable — a phase.bandpass and a logamp.bandpass component with no prior. freq (a ChannelBlocks) sets the segments; ChannelBlocks(1) is a free value per channel.

Either group of a Bandpass model may be empty. Fit one observable only by keeping just that group, e.g.

Bandpass(model = GainModel(; phase = default_bandpass_model().phase))

fits the phase bandpass alone. Uniform across every antenna.

A prior on a component (GainComponent(...; prior)) relates its values within each spectral window. Beside a shape under a zero-mean OUPrior, a group may add a mean: a level — a ConstantTerm per spectral window or coarser — and, for the phase, a delay — a Delay over the whole band or per group of spectral windows. The mean is flat, or under an IIDPrior:

shape = GainComponent(ConstantTerm(); Ti = GlobalTime(), Frequency = ChannelBlocks(1),
                      Feed = PerFeed(), prior = OUPrior(; scale = 50e6, σ = 0.1))
level = GainComponent(ConstantTerm(); Ti = GlobalTime(), Frequency = PerSpectralWindow(),
                      Feed = PerFeed())
delay = GainComponent(Delay(); Ti = GlobalTime(), Feed = PerFeed())
GainModel(; phase = (; level, delay, shape), logamp = (; level, shape))

Gustavo.Fring.default_fringe_model — Method
default_fringe_model(; rel_time = PerScan()) -> GainModel

The default model of a FringeClosure — the standard VLBI fringe model, phase components only (each key names its component; the order is the parameter order):

  1. mbd — per-scan wideband delay, feed-common.
  2. rel_delay — inter-feed delay offsets, Ti = rel_time, Feed = ExceptFeed(1): each other feed's instrumental group-delay offset from feed 1. With one feed per station it has no parameters.
  3. rate — per-scan rate, feed-common. There is no feed-specific rate: the inter-feed rate is negligible (EHT-HOPS convention). A genuine offset is added with merge(default_fringe_model(); phase = (; rel_rate = GainComponent(Rate(); Ti = PerScan(), Feed = ExceptFeed(1)))).

rel_time is the inter-feed delay's time segmentation: PerScan() (the default) fits an offset per scan, so its scan-to-scan scatter is an instrument-stability diagnostic and no column couples scans; GlobalTime() fits one offset per station for the whole track (the EHT-HOPS / rPICARD assumption) — bright scans pin it and weak scans inherit it, at the cost of coupling every scan into one system, solved after every scan is searched.

The closure fits no constant phase. A station's per-scan phase trades against the source's phase, so the data do not determine it without a source model; it stays in the data for imaging or self-calibration. The later solves do not need it: Bandpass aligns each scan's band-averaged phase per baseline and feed pair, and AdhocPhase removes each track's scan mean. The inter-feed delay is fit because a delay decoheres across the band, so leaving it in costs signal.

Add or replace a component with merge.

Gustavo.Fring.delay_closure — Method
delay_closure(spectra) -> DimArray

The triangle delay closure τ_ab + τ_bc + τ_ca of the baseline_delays of spectra, a baseline_spectra result, around every triangle of stations whose three baselines were measured. Over (Ti, Triangle, FeedPair), each Triangle labeled by its station names, for the products that pair a feed with itself: on a product (f, g) with f ≠ g each station enters the triangle once with each feed, so the feeds' delay difference does not cancel.

Station-based delays cancel around a triangle, so the closure of raw data is ≈ 0 up to noise, and a correct station-based solution keeps it there. A station-structure or sign mistake shows as residual baseline_delays after correction and, if it breaks closure, as a nonzero closure.

Gustavo.Fring.fringe_pfa — Method
fringe_pfa(snr, ncells) -> Float64

Probability of false alarm of a fringe detection: the probability that pure noise, searched over ncells independent (delay, rate) cells, produces a peak of at least snr (HOPS-style). With snr the amplitude over its per-component σ (|D| / √Σw for weights that are inverse variances per real component), a noise cell exceeds s with probability exp(−s²/2), so

pfa = 1 − (1 − exp(−snr²/2))^ncells

evaluated stably (≈ ncells·exp(−snr²/2) when small). See the "Detection statistics" section of the fringe-fitting manual for the derivation. pfa ≪ 1 marks a secure detection; pfa ≳ 0.01 means the peak is consistent with the noise sidelobe forest — a likely FALSE fringe. Returns NaN for non-finite inputs.

Gustavo.Fring.fringe_snr_cut — Method
fringe_snr_cut(pfa, ncells) -> Float64

Inverse of fringe_pfa in snr: the SNR at which a search over ncells independent (delay, rate) cells reaches false-alarm probability pfa — i.e. the effective SNR detection threshold implied by a PFA gate (fringe_pfa(fringe_snr_cut(pfa, ncells), ncells) = pfa). Gustavo.Fring.normalized_residuals — Method
normalized_residuals(data; dims = Frequency) -> DimStack

Every cut of data along dims divided by its weighted mean along dims. data is a processing set, a Measurement Set or a baseline_spectra result, laid out as baseline_spectra lays it out, with the weight the inverse variance of each real component of the visibilities. Layers, over the dimensions of baseline_spectra:

  • r = v / m, with m = Σ w v / Σ w over the cut. Along Frequency this removes each spectrum's phase, amplitude scale and band-mean source visibility, leaving whatever structure across the band the correction did not remove, a residual delay included. Along Ti it shows each channel's change about its mean over time.
  • var = 1 / (w |m|²), the variance of each real component of r, ignoring the noise in m.
  • scan_name, over Ti.

A flagged sample, or one with zero weight or non-finite data, is NaN in r and var, and so is every sample of a cut with no usable sample.

Gustavo.Fring.solve_adhoc_phasing — Method
solve_adhoc_phasing(rbar, wbar, antennas; gauge, smoother, tying, prior) -> DimStack

Solve globally-closing adhoc phases from coherently frequency-averaged residual baseline visibilities under the model

y[antenna pair, feed pair, ap] = φ_na(ap) − φ_nb(ap) + x[antenna pair, feed pair],

with the station phases φ on parameter nodes and one free source term x per (station pair, feed pair), constant over the scan. The free source term carries the source's EVPA, D-terms, and closure phase, so the station tracks are unbiased by source structure.

rbar is Σ_chan w·V_residual and wbar is Σ_chan w, both DimArrays over AntennaPair, FeedPair and Ti in any storage order, with the same lookups: station pairs labeled by station names, feed pairs by feed-index pairs, and Ti by the AP epochs in seconds. The coherent SNR² is |rbar|²/wbar. antennas names the stations; each one's position in it is its station index. The number of feeds per station is the largest feed index in the FeedPair labels.

Returns a DimStack: :phase (AntennaName(antennas) × Feed × Ti) is the per-(station, feed) adhoc phase in radians, NaN where unsolved; :covered marks the solved cells; :source (AntennaPair × FeedPair) is the fitted source phase, NaN where unidentifiable; :prior (AntennaName(antennas) × Feed) is the prior each track was fit under, its hyperparameters resolved, nothing where the track had no prior or no data.

Each track is its weighted mean over the scan plus the time structure: the constant is a gauge, since a per-station constant trades against the source terms, so every track is returned with zero weighted mean. The residual-rate slope is kept.

gauge sets the per-AP convention, applied after smoothing so that it does not change any baseline difference: PinAntenna holds its reference's phase at 0, ZeroSumPhase centers each AP on zero mean.

tying is the adhoc component's AbstractFeedTying. PerFeed() (the default) solves an independent track per feed; SharedFeeds() solves one feed-common phase, constrained by every correlation product and contributing zero inter-feed phase. Under PerFeed, an AP's products that pair different feed nodes join their blocks into one connected component with a single gauge freedom; blocks no such product joins keep a freedom each. The solved phases do not depend on how a station orders its feeds, and under SharedFeeds they do not depend on its feed basis either.

prior is the adhoc component's prior along time — nothing, a RandomWalkPrior or an OUPrior — for every station, or a vector holding one per station.

smoother is an AbstractAdhocSmoother selecting how the tracks are fit under prior after the solve; its AdhocOptions set the solve. The (φ, x) blocks are fit by alternating minimization for at most options.source_iters passes, stopping once no source term moves by more than options.source_tol radians beyond what per-station constants absorb (a constant moved between the tracks and the source terms leaves the model unchanged); source_iters = 1 fixes x = 0.

Gustavo.Fring.step_tests — Method
step_tests(residuals, intervals, station) -> Vector{NamedTuple}

An F test for a change in station's bandpass at each gap between two of its consecutive scans. residuals is a normalized_residuals result along Frequency, usually of scan averages (average(ps, ByScan())), and intervals the scan_intervals of the data before averaging.

Every series of residual spectra r on a baseline to station and a parallel feed pair (both feeds the same index) is split at the gap and fitted by one weighted mean spectrum per side, channel by channel, using the channels with at least two samples on each side. Summed over the series,

F = (Δχ² / ν₁) / (χ²_split / ν₂),

with Δχ² the χ² that two means remove relative to one, ν₁ = 2 per channel, χ²_split the χ² about the two means and ν₂ = 2(n - 2) per channel of n samples. Scatter between scans that is not a step (residual delays, phase noise) raises χ²_split along with Δχ², so F stays near 1 without a step. A residual delay that differs from scan to scan is such scatter, and one that changes across the gap is a step. A step at one gap also raises F at nearby gaps, where the one-sided means mix the two bandpasses; it is largest at the step.

One row per gap, in time order, with fields time (mid-gap, s), gap (its length, s), F, chi2_split, dof_split (ν₂) and nbaselines, the number of (baseline, parallel feed pair) series to station holding data. The scans are those where any such series has data; gaps across which those scans overlap and gaps with no channel to split are left out.
