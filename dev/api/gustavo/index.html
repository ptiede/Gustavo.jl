Gustavo.GUSTAVO_VISIBILITY_SCHEMA — Constant
GUSTAVO_VISIBILITY_SCHEMA

XRadio.VISIBILITY_SCHEMA with the three things Gustavo needs and MSv4 does not define: the EARTH_ORIENTATION block, the sideband and total_bandwidth of a spectral window (the UVFITS FQ table states both), and a sub_scan_name coordinate.

Pass it to XRadio.check and XRadio.write as schemas:

XRadio.check(ps; schemas = [GUSTAVO_VISIBILITY_SCHEMA])

Each addition is optional, so a store written by anything else still passes. What the specification buys is that a store which does carry them is examined rather than waved through, and that sub_scan_name is written under that name and listed among the coordinates of the variables it labels — without it the layer is written SUB_SCAN_NAME and a Python reader sees a data variable.

sideband cannot be restricted to ±1: a schema's permitted values are strings, so a stray 0 passes here and is caught by whatever reads it.

Gustavo.AdhocPhase — Type
AdhocPhase(; gauge = ZeroSumPhase(), model = default_adhoc_model(), smoother = PerTrackAdhocSmoother())
AdhocPhase(smoother; gauge = ZeroSumPhase())

The per-integration atmospheric-phase stage (adhoc phasing): solves the globally-closing per-AP station phase on the fringe/bandpass residual. What is fit is model, a GainModel holding the single adhoc component and its prior along time — see Fring.default_adhoc_model for the default (feed-common, OU prior) form. How the tracks are fit under that prior lives on smoother, a pluggable Fring.AbstractAdhocSmoother (Fring.PerTrackAdhocSmoother or Fring.JointKalmanSmoother, which requires the feed-common (SharedFeeds) model). The one-argument form takes the smoother and keeps the default model. gauge, an AbstractGauge, sets each AP's convention after smoothing, so the applied correction does not depend on it: PinAntenna holds the first of its references present in that AP at 0, and ZeroSumPhase centers every AP on the stations covered throughout the scan.

The solution's info holds nscans and priors: the prior each (station, feed) track was fit under, its hyperparameters resolved, over (AntennaName, Feed, Ti) with one Ti value per scan, its first AP epoch.

Gustavo.Bandpass — Type
Bandpass(; gauge = ZeroSumPhase(), model = default_bandpass_model(), smoother = JointSmoother())

The bandpass stage: the time-global phase / log-amplitude station bandpass, solved from the residual of whichever earlier solutions have already been applied, over every scan it is given. What is fit is model, a GainModel — see Fring.default_bandpass_model for the default and the component form JointSmoother accepts; each component's prior states how its values relate within a spectral window. How it is solved lives on smoother, a Fring.JointSmoother, which fits the complex visibilities against an explicit per-scan source coherence and so does not assume the calibrator is unresolved and unpolarized. gauge, an AbstractGauge, references the bandpass phase: JointSmoother imposes its constraints exactly in every step. JointSmoother solves one complex gain per (station, feed, frequency segment); a phase-only or amplitude-only model holds the other half at zero. The model is self-contained, so fitting the bandpass before or after the fringe closure is equally legal.

The phase the data leave free is a spectrum common to every station. PinAntenna moves the reference station's bandpass into every other station's track, and so into its prior, which suits a reference with a clean, stable bandpass; ZeroSumPhase() takes the mean over stations and biases none.

The bandpass is fit on data the fringe solution has already corrected, for example on calibrator scans held in memory:

fr = fit(FringeClosure(; gauge), fit(FringeSearch(), calibrator_scans))
bp = fit(Bandpass(; gauge), calibrate(fr, calibrator_scans; flag_bad = false, apply_flags = false))

Gustavo.ExecutionConfig — Type
ExecutionConfig(; progress = nothing, outer_executor = SerialScheduler(),
                inner_executor = DynamicScheduler())

Run-wide resources for fit and calibrate, shared by every pass over the data; per-fit options, the gauge included, live on the specification. Two runs differing only in their ExecutionConfig solve the same problem. Each scheduler is used exactly as configured, so the task count you set is the concurrency you get.

  • progress — (stage, done, total) callback per completed scan of each pass.
  • outer_executor — the across-scan scheduler, and thus how many scan groups are resident at once: SerialScheduler() by default; any other OhMyThreads Scheduler runs its task count of groups concurrently (GreedyScheduler(; ntasks) balances uneven scan lengths best). Groups are dispatched largest-first under every scheduler. Each resident group holds its visibilities, weights and flags plus the solve's working memory, so the task count is bounded by memory as well as cores.
  • inner_executor — the within-scan fan-out scheduler (DynamicScheduler() by default; SerialScheduler() for single-threaded within-scan solves).

Gustavo.FringeClosure — Type
FringeClosure(; model = default_fringe_model(), closure = Stationization(), gauge = ZeroSumPhase())

The station solve of a fringe fit: from the per-baseline detections of fit(::FringeSearch, ps), the per-(station, feed) delays and rates of model, a phase-only GainModel (see Fring.default_fringe_model). closure, a Fring.Stationization, holds the detection threshold pfa_max, which decides which detections are real fringes and so which stations are calibrated, and how inconsistent detections are weighted. gauge, an AbstractGauge, fixes what the detections leave undetermined; a ByComponent names components of model.

fit(FringeClosure(...), dets) solves the scans of dets, a vector of detection stacks, together, and returns a CalibrationSolution over their joint geometry. A model whose components are all per scan solves each scan on its own; a component spanning scans, such as a GlobalTime inter-feed delay, couples them, so close one scan at a time inside mapsets, or every scan at once:

dets = reduce(vcat, values(mapsets(g -> fit(FringeSearch(), g), groupby(ps, ByScan()))))
sol = fit(FringeClosure(; model = default_fringe_model(; rel_time = GlobalTime())), dets)

The models it fits: a Delay or Rate spanning the whole band (Frequency = GlobalFrequency()), under any feed scope, with a time segmentation no finer than a scan, and with no prior or a RandomWalkPrior, OUPrior or CARMAPrior along Ti with numbers for hyperparameters. Such a prior ties the component's values across its time segments, and so couples the scans: a segment no accepted detection constrains takes the prior's interpolation of its neighbors rather than being flagged. A drifting inter-feed delay is a flat level beside a mean-zero drift:

rel_delay = GainComponent(Delay(); Ti = GlobalTime(), Feed = ExceptFeed(1))
rel_drift = GainComponent(Delay(); Ti = PerScan(), Feed = ExceptFeed(1),
                          prior = OUPrior(; scale = 3600.0, σ = 3.0e-11))
model = merge(default_fringe_model(); phase = (; rel_delay, rel_drift))

A segmentation that splits a scan (a TimeBlocks shorter than the scans, PerIntegration) asks for values the search does not measure and is rejected. It fits no constant phase, no dispersion (Dispersion) and no per-band-group delay (a FreqGroups-segmented Delay).

The solution's info holds ncomp, the number of fringe groups the detections form, and the (station, feed, scan) triples no accepted detection constrains (flagged_ant, flagged_feed, flagged_scan), which calibrate! flags.

Gustavo.apriori_calibrate! — Method
apriori_calibrate!(ms::XRadio.MeasurementSet; tsys = ScanMean(), min_elevation = 0.0,
                   tsys_placeholders = (999.0,), quantization_efficiency = nothing) -> ms

Put the visibilities of ms in janskys, in place, from the system temperatures and gain curves the Measurement Set records (XRadio.system_temperatures, XRadio.gaincurves), whether they came from FITS-IDI (XRadio.fitsidi2msv4) or ANTAB (XRadio.read_antab!).

Each receptor's system equivalent flux density is T_sys / (DPFU · g), with g its gain curve at the source's elevation and DPFU the curve's sensitivity. A visibility on baseline (a, b) relating receptors (fa, fb) is multiplied by √(SEFD_a · SEFD_b) and its weight divided by SEFD_a · SEFD_b, so the weight stays 1/σ² of the visibility it describes. Receptors come from feed_pairs.

The same visibility is divided by η_a · η_b and its weight multiplied by (η_a · η_b)², which corrects the loss of correlated amplitude to the correlator's quantization. η is each antenna's quantization efficiency, from the digitizer_levels variable of the antenna dataset: 2, 3 and 4 levels give 2/π, 0.8098 and 0.8825, the weak-signal efficiencies with optimal thresholds (Thompson, Moran & Swenson, Interferometry and Synthesis in Radio Astronomy, ch. 8). A Measurement Set without digitizer_levels needs quantization_efficiency: one number for every antenna, or a Dict from antenna name (string or symbol) to η holding every antenna. Where digitizer_levels are recorded, quantization_efficiency supplies η only for the antennas whose level count has none tabulated, and must be given for them: one number for all of them, or a Dict naming no other antenna.

tsys places the system temperatures, which are sampled on their own clock, on the visibilities' times: ScanMean, LinearInTime or NearestInTime. A system temperature that is not positive or equals one of tsys_placeholders (values written for "not measured") counts as unmeasured before it is placed; the store keeps it. Elevations come from the antenna positions, the field phase center and the time; a source below min_elevation (radians) has no usable gain.

A sample whose antennas lack a usable system temperature, gain curve or elevation is flagged and keeps its visibility and weight. Autocorrelations are flagged. The visibility units become Jy; a Measurement Set whose visibilities are already in janskys is an error, as is one that records no system temperatures or no gain curves.

Gustavo.calibrate! — Method
calibrate!(sol::CalibrationSolution, ps::ProcessingSet;
           flag_bad = true, apply_flags = true, post = identity,
           exec = ExecutionConfig()) -> ps
calibrate!(sol::CalibrationSolution, ms::MeasurementSet;
           flag_bad = true, apply_flags = true, exec = ExecutionConfig()) -> ms

Apply a fitted solution, or any selection of one (sol[:phase], sol[:phase, :mbd], filter(pred, sol)), to the data in place: each Measurement Set has the gains of the components sol holds divided out (V → V / (g_a·conj(g_b)), w → w·|g_a g_b|²), then the flags sol records and post applied. post modifies the Measurement Set it is handed and returns it. To keep the data, use calibrate; copy and read of in-memory data share its arrays.

gauge = PinAntenna("AA")
fr = fit(FringeClosure(; gauge), fit(FringeSearch(), ps))
mapsets(groupby(ps, ByScan())) do g
    calibrate!(fr, g; flag_bad = false, apply_flags = false)
    fit(AdhocPhase(; gauge), g)
end

A gain cell that is zero or non-finite gives a NaN visibility and a flag (flag_bad = true) or leaves the sample as it is (flag_bad = false). apply_flags flags the baselines of each (station, scan) the fit behind sol left unconstrained (the fringe fit records these): their gains are identity, so the data would pass through uncalibrated. The flagged samples keep their visibilities and weights.

The solution need not have been fit on this data, nor on its sampling. Each sample is placed in the segment of sol it belongs to, by the identity the segmentation is defined on: a PerScan component by scan name, a PerSpectralWindow one by spectral window name, a TimeBlocks or InstrumentScans one by the solve's own bin formula, a PerIntegration one by exact epoch. So a solution segmented more coarsely than the data applies, while one segmented more finely is refused. A ChannelBlocks or FreqGroups component places each channel by its center frequency and width: the data's channel must be a channel of the solve, no wider, so averaged channels are refused.

Stations are matched by name against the solution's geometry. The baselines of a station the solution does not name are flagged under apply_flags, as an unconstrained station's are, and otherwise left uncorrected; either way with a warning. A solution that shares no station with the data is refused. A store opened with mode = "r+" is calibrated in place only if its visibility, weight and flag layers hold one time per chunk; one chunked over several times is refused, since tasks writing into one chunk would lose each other's writes. exec supplies the schedulers and progress callback; a single Measurement Set uses only its inner_executor.

Gustavo.each_group — Method
each_group(f, ctx::SolveContext) -> Vector

Read each scan group of the solver's data and return f(group) for every group, in group order. group is a ProcessingSet of in-memory Measurement Sets, one per spectral window of the scan. Groups run on the run's outer scheduler, heaviest first, and the progress callback is told of each.

f may run concurrently across groups, so it must not write shared state other than θ slots belonging to its own scan; it returns its scan's contribution instead, and the caller combines the returned values.

Gustavo.feed_pairs — Method
feed_pairs(ms::XRadio.MeasurementSet) -> Matrix{Tuple{Int, Int}}

The (feed_a, feed_b) pair each stored product relates on each baseline, indexed [product, baseline] in ms's own order. A product names one receptor of each antenna, resolved against that antenna's polarization_type: the letter's position there, or, for an antenna whose receptors are all of the other basis (X/Y for an R/L letter, or the reverse), the letter's position in its own basis (R, X first; L, Y second). Gustavo.load_uvfits — Function
load_uvfits(path; element_type = nothing, gap = 10.0) -> XRadio.ProcessingSet

Load an AIPS random-groups UVFITS file as an XRadio.ProcessingSet holding one Measurement Set per (scan, FQ row, subarray), keyed :<source>_spw_<n>[_sub_<n>]_scan_<n> (e.g. :src_3C273_spw_0_scan_1); the sub_<n> segment appears only when the file carries more than one AN table, and each subarray's Measurement Set takes its antennas from its own. The scans are the rows of the NX table; a file without one is split into scans where more than gap seconds pass between consecutive record times, the rule XRadio.fitsidi2msv4 applies. A record outside every NX scan joins the NX scan whose records lie within gap seconds of it; the rest are split into further scans by the same rule, numbered after the NX rows, with a warning. Each baseline is stored in one order, the lower antenna number first: a record whose BASELINE names the higher one first is conjugated, its uvw negated and its cross-hand products swapped (RL with LR).

Each Measurement Set conforms to GUSTAVO_VISIBILITY_SCHEMA: dense (polarization, frequency, baseline_id, time) visibility, flag and weight arrays in Julia order, uvw in meters, the Earth-orientation block of the AN table, and each window's sideband and total bandwidth. When the FREQ axis holds one channel, the IFs of an FQ row are the channels of one spectral window; when it holds several, each IF is a window of its own, numbered (FQ row - 1) * nIF + IF - 1. VISIBILITY.units is the file's BUNIT (JY written Jy, UNCALIB written uncalib); a file with none is written uncalib, with a warning. Where the file states INTTIM, each record's value is written to effective_integration_time over (baseline_id, time), 0 for a slot no record fills, and the time axis' nominal integration_time is the largest of them; otherwise effective_integration_time is absent and integration_time is the smallest positive spacing of the scan's times.

A record's weight w becomes:

recordweightflag
w > 0, +0.0wfalse
w < 0, -0.0abs(w)true
no record0true

with the visibility read as stored, or NaN for a (time, baseline) slot no record fills.

element_type is the real float type the visibilities and weights are stored at; nothing takes the precision the file itself holds, so a double-precision random-groups file is read as ComplexF64/Float64. uvw is always Float64.

Visibilities are read verbatim: AIPS UVFITS shares MSv4's phase sense. See Conventions.

Provided by the GustavoFITSFilesExt extension; load FITSFiles to enable.

Gustavo.mapsets — Method
mapsets(f, src; exec = ExecutionConfig()) -> OrderedDict

Apply f to each unit of data in src, read into memory, and return f's results under the units' keys, in src's order: k => f(read(u)) for each k => u of src, with the units scheduled across tasks and progress reported. src is an ordered keyed collection whose values are Measurement Sets or processing sets: a ProcessingSet (its Measurement Sets, keyed by name), a groupby result such as groupby(ps, ByScan()) (its processing sets, keyed by label), or an OrderedDict of either. The fringe and adhoc fits need every spectral window of a scan, so a body that fits them takes scan groups.

Each unit is read with arrays of its own, copied where the source is already in memory, so f may modify it in place (calibrate!) without changing the source or another unit. A unit is held only while f runs, unless f returns it: return solutions or reduced data, and write full-size data out from inside f. Results that are Measurement Sets or processing sets form one processing set again with XRadio.ProcessingSet: ProcessingSet(out, metadata(ps)) for Measurement Sets, ProcessingSet(out) for processing sets.

Units run on exec's outer_executor, largest first, and a unit's Measurement Sets are read on its inner_executor. With more than one task, f must be safe to run concurrently. exec.progress receives (:mapsets, done, total) as units finish.

gauge = PinAntenna(1)
averaged = mapsets(groupby(ps, ByScan())) do g
    fr = fit(FringeClosure(; gauge), fit(FringeSearch(), g))
    calibrate!(fr, g; flag_bad = false, apply_flags = false)
    return average(g, ByScan())
end
bp = fit(Bandpass(; gauge), ProcessingSet(averaged))

Gustavo.normalize_by_autocorrelations! — Method
normalize_by_autocorrelations!(ms::XRadio.MeasurementSet) -> ms

Make the cross-correlations of ms correlation coefficients, in place. Each visibility on baseline (a, b) relating feeds (fa, fb) is divided by √(A_a · A_b), where A_a is the amplitude of antenna a's autocorrelation of feed fa at the same channel and time, and its weight is multiplied by A_a · A_b, so the weight stays 1/σ² of the visibility it describes. Feeds come from feed_pairs, not from the product labels.

A sample whose two autocorrelations are not both present, unflagged, finite and positive is flagged instead, and left undivided. The autocorrelation baselines are then flagged: MSv4 keeps them, but they are no longer data.

A Measurement Set with no autocorrelation baselines is left unchanged: its visibilities are taken to be normalized already, or to need no normalization.

Gustavo.solve — Function
solve(solver::AbstractSolver, ctx::SolveContext) -> NamedTuple

Fit solver's own model: fill ctx.θ and return the solver's diagnostics, which become sol.info. The data are read with each_group, once per pass the solve needs; a solve that iterates (a residual re-search, say) calls it once per round. Gustavo.supports_antenna_heterogeneity — Method
supports_antenna_heterogeneity(solver::AbstractSolver) -> Bool

Whether solver handles a gain model whose component signatures differ across stations. Default false: the runner then rejects a heterogeneous compiled model aimed at the solver (Calibration.require_antenna_uniform), naming the differing components and their per-station signatures, so an undeclared solver never receives θ blocks it would silently leave unsolved.

A solver that declares true must write its solve as a loop over the station blocks the layout supplies — Calibration.antenna_blocks — rather than assuming one rectangular (…, nant) leaf per component. A solver whose solving is delegated to a pluggable object forwards this question to it, so the generic also answers for those objects — Bandpass asks its smoother.

Gustavo.weight_scales — Method
weight_scales(ms::MeasurementSet) -> DimArray

The factor per (polarization, baseline) that makes the weights of ms inverse variances of each visibility component, estimated from the scatter between consecutive time samples of one channel. For two such samples, z = (V₁ − V₂)/√(1/w₁ + 1/w₂) has E|z|² = 2 when the weights are inverse variances and the signal does not change between them, so the factor is 2 ln 2 / median|z|² (the median of an exponential with mean 2 is 2 ln 2). Pairs with either sample flagged are skipped.

The signal cancels as long as its phase moves little in one integration; an uncorrected rate r moves it by 2π r τ over an integration of length τ.

Autocorrelations, and cross-correlations with no unflagged consecutive pair, get 1; a warning names the cross-correlations among them that hold unflagged data. Apply the factors with scale_weights!.

Gustavo.write! — Method
write!(out::XRadio.ProcessingSet, unit::XRadio.ProcessingSet) -> out

Write the data variables of each Measurement Set of unit into the Measurement Set of the same name in out, a store opened with open(ProcessingSet, path; mode = "r+"). A member holds some of the stored times and all of every other axis, as a mapsets unit of a groupby does; data variables are the layers GUSTAVO_VISIBILITY_SCHEMA does not call coordinates.

Write the template with chunks no longer in time than the shortest unit, such as chunks = (; time = 1); the store's consolidated metadata stays valid.

    calibrate!(sol, g)
    write!(out, g)
    return nothing
end

Gustavo.write_uvfits — Function
write_uvfits(path, ps::XRadio.ProcessingSet; overwrite = false) -> path

Write ps as an AIPS random-groups UVFITS file (AIPS Memo 117) that load_uvfits reads back as ps. An existing path throws unless overwrite = true.

The set must describe one observation UVFITS can hold:

  • one source and field; select one first, e.g. with filter;
  • one frequency setup: every scan holds the same spectral windows (channel frequencies, widths, sidebands and total bandwidths), and the windows of one scan share their time and baseline axes;
  • one polarization set, a contiguous run of AIPS Stokes codes (RR, LL, RL, LR = -1…-4, XX, YY, XY, YX = -5…-8);
  • one subarray: an antenna name states one position, mount and receptor set across the set, and no two scans overlap in time. A set read from a file of several subarrays throws rather than being written as one.

Each scan's windows become the IFs of one FQ row, ordered by frequency, and the records run in (time, baseline) order, one NX row per scan. A single window is written one channel per IF, the layout load_uvfits reads as one window; several windows are written one per IF with their channels along the FREQ axis, which requires equal channel counts and channels evenly spaced by the channel width. Several one-channel windows have the single-window layout and so read back as one window whose channels are the windows; they must then share their channel width, sideband and total bandwidth. The FREQ axis' reference value is the lowest window's reference frequency, which every window reads back with.

Visibilities are written verbatim, at their own float type (Float32 as BITPIX = -32, Float64 as -64), and uvw in light-seconds. A flagged sample's weight is written negated, -0.0 for a weight of zero. A (time, baseline) record whose every sample is flagged with weight zero is not written; such a sample in a written record has visibility 0, which it reads back with. BUNIT is the visibilities' units (Jy as JY, uncalib as UNCALIB), and INTTIM the effective_integration_time, else the time axis' integration_time. DATE is the Julian Date of the day's 0h UT and the fraction of that day.

The AN table's Earth-orientation cards come from the earth_orientation attribute (GUSTAVO_VISIBILITY_SCHEMA). A set without one, such as a store from XRadio.fitsidi2msv4, is written with GSTIA0 and DEGPDY computed from RDATE (GMST at 0h UT, IAU 1982, UT1 − UTC taken as zero) and the other cards at load_uvfits' defaults, with a warning naming them.

Not written: the sub-datasets other than antenna and field (system_calibration, gain_curve, weather, phase_calibration), sub_scan_name, scan_intents, and every attribute UVFITS has no place for. The file is not a byte copy of any file the set was read from.

Provided by the GustavoFITSFilesExt extension; load FITSFiles to enable.

fit(solver::AbstractSolver, ps::ProcessingSet; exec = ExecutionConfig()) -> CalibrationSolution
fit(solver::AbstractSolver, ms::MeasurementSet; exec = ExecutionConfig()) -> CalibrationSolution

Solve solver (Bandpass, AdhocPhase or a third-party AbstractSolver) on ps, one scan group (groupby(ps, ByScan())) at a time. ps is never modified. Narrow the data by subsetting ps first. A Measurement Set is fit as a processing set of one.

To fit data an earlier solution has corrected, correct the data first: calibrate! on data read into memory, or inside mapsets.

The solver carries its own gauge (solver_gauge); fit resolves its station codes against the data's antenna table. exec (an ExecutionConfig) supplies the schedulers and progress callback.

The solution is a CalibrationSolution: the solved components, the solver's diagnostics in sol.info, and the solver, its gauge included, as text in sol.spec.

StatsAPI.fit — Method
fit(search::FringeSearch, ps::ProcessingSet; at = nothing, exec = ExecutionConfig()) -> Vector{DimStack}

Fringe-search every scan of ps: per scan, every cross (antenna pair, feed pair) cell is searched over search's delay and rate windows, across all the scan's spectral windows. Returns one DimStack per scan, in scan order, over AntennaPair × FeedPair with the layers delay (s), rate (Hz), phase (rad, at the scan's mean time), amp, snr, pfa and valid. No cell is gated: FringeClosure's pfa_max decides which are real fringes.

Each stack's metadata records the scan: scan (its name), epoch (its mean time), geom (its DataGeometry), search, ncells (the trial count of the recorded pfa), freq_mean, and freq_rms and time_rms (the RMS spreads of its channels and times, which set the uncertainty of a delay and a rate).

With at, a CalibrationSolution holding delay and rate terms, every cell is instead measured at the delay and rate at predicts for it (τ_{a,fa} − τ_{b,fb}), so a fringe too weak for the blind search is still measured. Its pfa is over search.steer_cells trials. A cell is NaN where at holds no constrained value for either station's feed in the scan.
